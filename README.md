# ABP (AI Business Platform) — ボートレース平和島様向け提案モック

ボートレース平和島様への提案用に、瑞鳳グループ様向けに構築したABPモックのデザインシステム・コンポーネントを流用して新規構築した、独立したプロジェクトです。

**瑞鳳グループ様のリポジトリ・データとは完全に分離しています。** 表示データはすべてボートレース平和島様向けのダミーデータで、瑞鳳グループ様の実データは一切含まれていません（意図的な設計判断です。詳細は`瑞鳳/ABP_ボートレース平和島展開検討.md`を参照）。

## 開発方針

- **React** + **Vite** + **Tailwind CSS**（v4）
- コンポーネント指向。共通UIパーツは瑞鳳グループ様向けabp-mockと同一のものを流用
- 画面表示はすべて `src/data/*.json` のダミーデータで動作する（API・DB接続なし）

## セットアップ・ローカル開発

```bash
npm install
npm run dev
```

`http://localhost:5174` で確認できます（瑞鳳グループ様向けabp-mockと同時に起動してもポートが衝突しないよう、こちらは5174番を使用）。

```bash
npm run build    # 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果をローカルで確認
```

## この提案モックの前提となる組織構造

ボートレース平和島は、以下の3者が役割を分担して運営しています。

- **府中市**（施行者・事業経営）：総務課／経営企画課／開催運営課
- **京急開発株式会社**（施設所有・管理運営）
- **日本モーターボート競走会**（競技運営）

また、本場（ボートレース平和島）に加え、場外発売所5拠点（BTS河辺・BTS横浜・BTS黒石・オラレ上越・オラレ刈羽）を展開しています。ヘッダーの「表示軸セレクター」（施設全体／組織別／部課別／係別／拠点別）と、AI分析ダッシュボードの「全拠点集計／拠点別」切り替えは、この構造を反映したものです。

## 瑞鳳グループ様向けabp-mockとの主な違い

| 項目 | 瑞鳳グループ様向け | 本プロジェクト |
| --- | --- | --- |
| 組織モデル | 1グループ・7社・複数事業部の複合企業体 | 3団体（府中市／京急開発／競走会）による役割分担 |
| 多拠点比較の単位 | 11店舗（パチンコホール） | 本場＋場外発売所5拠点 |
| ダッシュボードの詳細分析軸 | 機種分析・レート分析（パチンコ特有） | レース種別分析・舟券種別分析・発売チャネル分析 |
| AI通知センターの中身 | 実際の店舗運営マニュアル（ハウコレ）から検出した実データ | 「AIが資料を確認し報告する」体験を示すイラストレーティブなサンプル（実データなし） |
| Feature ID／CHANGELOG運用 | 導入済み（`docs/ABP_FEATURE_REGISTRY.md`等） | 未導入（必要になったタイミングで別途起票） |

## 公開環境（GitHub → Vercel）

瑞鳳グループ様向けと同様に、GitHub Push → Vercel自動デプロイの運用を想定しています。リポジトリ・Vercelプロジェクトは瑞鳳グループ様向けとは別に新規作成してください。
